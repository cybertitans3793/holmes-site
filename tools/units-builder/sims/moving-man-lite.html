About Custom Functions

You can type an expression for position as a function of time, t (in seconds).

Examples:

  • x(t) = 3 * t + 2
  • x(t) = 2*sin(t)
  • x(t) = pow(t,2) or t^2
  • x(t) = 7*pow(sin(t),2)
  • x(t) = sqrt(t * 4)

Type only the right-hand side. Multiplication must be written out: 3 * t, not 3t.
